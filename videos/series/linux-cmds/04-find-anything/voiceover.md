You know it is in there somewhere. Three commands to find anything.

## [0:05-0:19] Find
Find walks a folder tree looking for files. Match by name with dash name, and quote the pattern so the shell does not expand it first. Or match by type, like dash type d for directories.

## [0:19-0:32] Locate
Locate is faster, because it searches a prebuilt index of every file name on the system instead of walking the disk. Run updatedb to refresh that index.

## [0:32-0:45] Grep
Grep searches inside files for text. Dash r searches every file in a folder, and dash n shows line numbers.

## [0:45-0:58] Grep options
Add dash i to ignore upper and lower case, or dash l to list just the file names that match.

## [0:58-1:05] Recap
Find for names, locate for speed, grep for contents. Together they can track down anything on a machine. That is the whole toolbox.
