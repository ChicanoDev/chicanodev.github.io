## [0:00-0:05] Hook
Nobody memorizes every command. Here is how professionals look things up, and it is not magic.

## [0:05-0:19] Man
Man opens the manual for any command. It opens in a pager, so use the arrow keys to scroll, and press q to leave.

## [0:19-0:30] Help
Many commands also take dash dash help for a quick summary of options, which is faster than the full manual.

## [0:30-0:43] History
History shows the commands you ran before. Pipe it to tail for the latest few. Control r searches it as you type, so you never retype a long command.

## [0:43-0:56] Alias
Alias gives a long command a short name. Now ll runs ls dash la. Put it in your bashrc and it sticks.

## [0:56-1:06] Echo
And echo prints text or variables. Home and shell are two you will use all the time.
