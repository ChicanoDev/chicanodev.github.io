## [0:00-0:05] Hook
Can you reach the internet? Download a file? Bundle a folder? Six commands, one minute.

## [0:05-0:18] Ping
Ping sends tiny packets to a host and times the reply. Dash c limits how many. If you get replies, the network path works. Without dash c, it runs until you press control c.

## [0:18-0:30] Curl
Curl talks to web servers. Dash s is silent, dash capital i fetches only the headers. A 200 means okay. It is a handy way to check whether a site is up.

## [0:30-0:43] Wget
Wget downloads a file to disk. Dash q keeps it quiet. Now index dot html is sitting in your folder.

## [0:43-0:57] Tar
Tar bundles files into one archive. Create, gzip compress, file. Then dash t lists what is inside.

## [0:57-1:11] Zip
Zip does the same in the format everyone knows. Dash r means recursive, and unzip dash l lists the contents.
